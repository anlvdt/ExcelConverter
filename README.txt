Excel Converter v1.2.0
Run ExcelConverter.cmd on Windows with desktop Microsoft Excel installed.
Extract ALL application files together; preserve ExcelConverter.Core.psm1 and LongPathIO.cs.
Supports XLS/XLSM/XLSB -> XLSX, long local OneDrive/SharePoint synced paths.
Extract input ZIP/7z first. Existing XLSX is reported as AlreadyXlsx.
Originals are kept by default. Review CSV from the Reports button.
See README.md and docs/AUDIT-2026-10-26.md for usage and verification limits.
